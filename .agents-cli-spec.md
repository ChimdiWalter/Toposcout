# TopoScout build specification

## Problem
Scientific-image analysis often requires manual quality control, segmentation, structural validation, retry decisions, measurement, and reporting. TopoScout automates that workflow while keeping scientific measurements deterministic.

## Hackathon track
Taskmaster: event-driven autonomous routing from new image to validated output and report.

## Core workflow
RECEIVED -> QC -> SEGMENT -> TOPOLOGY_AUDIT -> ACCEPT | RETRY | HUMAN_REVIEW | REQUEST_REACQUISITION -> REPORT

## Safety / scientific constraints
- Gemini must never invent measurements.
- Numerical measurements come only from deterministic tools.
- Agent actions are bounded to ACCEPT, RETRY, HUMAN_REVIEW, REQUEST_REACQUISITION.
- Maximum one automatic retry in MVP.
- The generic architecture is demonstrated on biological images; cross-domain claims must be framed as extensibility, not validation.

## Success criteria
1. A local image can be processed end-to-end.
2. QC, segmentation, topology audit, bounded action, artifacts, and JSON report are produced.
3. ADK exposes these tools to Gemini 3.5 Flash.
4. Unit tests cover QC, topology and retry policy.
5. Next step is event-driven Cloud Storage -> Cloud Run deployment with Firestore state.
